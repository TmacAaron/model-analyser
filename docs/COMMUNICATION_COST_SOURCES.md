# 通信步骤的实际来源

分析后，在「成本与覆盖来源」选择一条通信和所关心的指标。也可以从模型耗时的聚合明细打开实际通信步骤。选择「复核此通信的实际运算」可查看固定配置下的结果。若 Decode 有多个步骤，先选择其中一个实际步骤。

- **消息表达式。** 方案通信显示原公式与实际模型参数。图内通信保留固定资产、展开前的公式与实际调用的局部参数，并展示展开后的张量端点和物理设备组。
- **参数绑定。** 在「实际调用参数绑定」可从本页发送、接收和生效的自定义耗时算式追到实际读取的符号。方案通信记录根参数对同名工作负载字段的遮蔽，图内通信记录原生调用的父域、实际实例及重复索引。生效候选保留原覆盖序号，即使其数值与默认值相同。
- **逐设备与组总量。** 统一消息用参与数量计算组总量。`send_recv` 各计算一个发送端与接收端。逐设备声明按原顺序累计发送和接收，各设备的算法系数只乘一次。非均匀时可从不可用的每成员指标打开逐设备明细。
- **端点布局。** 「实际通信端点布局」显示本次调用源端和目标端的展开张量、布局组、全局维度、覆盖方式与数据类型。每张设备下可展开源端或目标端，查看实际 mesh 坐标、切片、有效和填充后的尺寸、元素数以及副本数。`send_recv` 的设备明细只展示各自承担的端点。张量数据类型和消息数据类型分别记录，消息字节仍由实际荷载声明求值。
- **关联存储。** 「通信关联存储」显示端点引用的存储及其规范存储 ID。打开设备下的「本卡关联存储」，每个底层分配只列一次，并标明源端、目标端及声明临时缓冲角色。可复核该设备的每副本字节、总分配和分配公式。未声明分配和分配在其他设备分别显示。存储每页最多 20 项，可独立于设备翻页。
- **链路与耗时。** 展示作者声明、图内角色绑定后的链路和配置覆盖后生效的链路。带宽与延迟模式取最大的发送算法流量除以带宽，再加启动轮数乘单轮延迟。固定和自定义耗时各自使用其实际声明。

报告按每页 20 台设备显示。参数链只收录本页公式实际读取的符号，最多 256 个参数入口、步骤和候选各 256 个。达到预算时保留已取得的证据与原指标。实际 Decode 步骤沿用原报告的诊断身份，包含各设备发送量不同而无统一每成员值的情况。

当前导出为 `communication_cost_source` 第 4 版，包含固定输入、实际步骤上下文、端点布局、当页设备和当页存储。设备证据跟随原消息顺序。同一个张量 ID 同时用于两端时，两端各自的布局仍分别记录。运行 `npm run verify:leaf-source -- <文件>` 可复算并逐字段核对四个版本。可从本卡明细进入[逐卡分配推导](LAYOUT_SOURCES.md)并单独导出。

此处是通信求值器的理论网络耗时。多流执行区间在聚合来源或时间线查看。显存访问、临时空间和计算量分别由各自的成本声明决定。
