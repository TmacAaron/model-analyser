# 模型与模块聚合来源

在画布的「成本与覆盖来源」选中模型或模块，再点「复核此指标的聚合运算」。可以查看理论耗时、逻辑读写、HBM 和具体计算分类的成员。每页显示 20 项。点击成员可保留当前指标并跳到算子、通信、融合组或实际 Decode 步骤。

| 结果范围 | 可复核的实际运算 |
| --- | --- |
| 单设备串行模型、模块 | 按引擎原顺序累加对应的叶成本 |
| 分布式模型和模块的物理工作及流量 | 按实际成员和计算分类累加。整个融合组位于所选范围时，用融合后的成本替换成员 |
| 分布式串行模型耗时 | 从零开始按实际执行顺序累加屏障耗时，包括独立的通信步骤 |
| 多流模型和模块耗时 | 模型取最后一次调度事件的结束时刻，模块取实际成员最晚结束减最早开始 |
| Decode 完整序列 | 累加实际步骤的对应指标，保留步号、上下文与输入哈希 |

导出页包含固定资产、场景、范围、指标及该页运算，使用 `npm run verify:leaf-source -- <文件>` 离线复算。复算检查全体成员、原指标与页内容。下一页的累计值承接前几页的实际运算顺序。

这里追溯聚合层的操作数和调度时间。并行局部公式、融合内部成本、通信公式及模型逻辑有效工作量的完整来源仍在推进。不可用指标保留原诊断。
