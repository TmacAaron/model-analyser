修复页支持取消与重试“正文预览”。取消的是派生预览，原文草稿继续自动保存，界面明确说明这一点。正文身份按钮也在后台改写，保留原YAML注释；期间新输入或导航会使旧改写失效。空正文同样显示解析诊断，不误当成已经校验的项目。

自动保存状态机等待异步校验完成。新一代编辑终止尚未提交的旧校验，旧正文已写入的草稿不丢失；最新一代按原基线继续保存。若旧正式提交已经开始，则继续以原请求ID确认其结果，再按确认后的修订保存新编辑，不能把取消校验变成取消已开始的提交。校验失败可重试，已经写好的草稿不重复写。页面关闭提示包含正在等待校验的状态。
