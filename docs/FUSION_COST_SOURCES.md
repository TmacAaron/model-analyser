# 融合成本来源

在当前配置的分析结果中点击「融合执行成本」里的指标，或从模型和模块的聚合运算下钻到融合组，再点「复核此融合的实际运算」。从设备项可继续打开成员算子和附加项的实际方程。

| 范围 | 可复核的计算 |
| --- | --- |
| 组工作量、逻辑流量和 HBM | 依次加各设备的实际融合后成本；设备页按成员顺序加上声明的附加成本 |
| 设备的成员合计耗时 | 每个成员与附加项先按参与设备取最大值，再按实际顺序累计屏障 |
| 设备的整体覆盖耗时 | 采用固定值、自定义公式或按融合后计算分类与 HBM 字节运行的 Roofline |
| 组耗时 | 串行取最慢设备；多流使用实际融合步骤的结束时间减开始时间 |

取消物化的证据列出过滤掉的读取、写入和临时存储，并显示已解析设备上的生效分配。保留项继续使用原访问 ID、分配和公式。附加项可以追到原声明或实际设备的局部布局实参。成员耗时是融合策略的数学分量，执行时间线用一个融合跨度。

选择设备的耗时来源后，自定义公式可追到预设的实际调用参数及其父域。手工声明的融合组使用配置根作用域。相同数值的候选仍保留实际覆盖身份。Decode 步骤使用对应的工作负载。Roofline 的执行工作量和 HBM 输入可直接打开同一设备的融合后成本，再按成员及附加项下钻。不同计算分类使用运算所记录的位置与完整分类，即使工作量相同。

每页最多 20 个操作数或资源项，参数图和 Roofline 记录有独立预算。当前导出为 `fusion_cost_source` 版本 2，使用 `npm run verify:leaf-source -- <文件>` 可核对版本 1 和版本 2 的固定输入、实际步骤和整页证据。数学成员和附加公式可在[逻辑工作量来源](LOGICAL_WORK_SOURCES.md)单独复核。存储规则和物化结果见[逐卡布局与分配推导](LAYOUT_SOURCES.md)。
