# 成本来源面板的交互开销

打开“成本与覆盖来源”时，面板为当前结果和 Decode 步骤建立模型、模块、算子、存储及逐卡范围索引。它按选中的范围生成指标和对应方程入口。切换指标、输入搜索或更改显示单位时复用该步骤的索引。搜索保留匹配总数，显示前 100 项，并保留当前选中范围。

参数、资产依赖、求值假设和固定硬件详情按需展开。参数来源通过实例 ID 和参数键匹配，保留求值顺序。长列表每页 20 项。共享公式引用和数值覆盖声明直接显示第一页，可继续翻页。原值、单位、固定修订与实际 Decode 步骤仍由相同结果和计算来源提供。

## 浏览器观测

使用引用算子模板展开 9,999 个算子，各声明一个默认值为 `7 count` 的 `Width` 参数。待分析结果就绪后，在同一隔离浏览器内点击打开面板，记录至第二次动画帧回调的用时。每轮关闭面板并确认内容卸载，再重新打开。改动前使用 `76a870d` 的构建。以下记录包含浏览器调度与渲染，只用于比较这一输入上的面板开销。

| 观测项 | 改动前 | 改动后 |
| --- | ---: | ---: |
| 三次打开用时（ms） | 1289.0 / 1290.8 / 1190.3 | 25.3 / 23.7 / 26.9 |
| 结果范围下拉项 | 100 | 100 |
| 收起时已渲染的参数行 | 60 | 0 |
| 收起时已渲染的硬件 JSON 块 | 2 | 0 |

`npm run test:e2e -- tests/e2e/cost-source-scale.spec.ts --workers=1` 复现当前观测，检查参数翻页、收起后卸载、末尾算子原始耗时和搜索无匹配时的当前选择。各结果的首次索引、打开参数详情时的一次线性匹配、画布投影和大图 DOM 仍有主线程开销。
