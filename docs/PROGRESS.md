## 检查点 8：设备分片、局部存储和通信求值原语

实现多设备核心的三个独立接口和可执行参考案例。它们尚未接入方案选择器/局部算子成本/整图调度，工作台仍明确拒绝多设备报告，不将原语测试当作完整 P3/P4 验收。

- `partitionTensor` 将已知逻辑 shape 映射到实际设备。even 要求整除；padded 分开保留有效切片和物理补齐尺寸；explicit 检查每设备/每轴切片、范围、覆盖、重叠和未分片 mesh 轴上的副本一致性。多轴分片使用不同 mesh 轴，未使用的 mesh 轴形成真实副本。manual 保留用户局部形状和 copies，并明示没有证明完整覆盖；partial 保持未归约语义，不伪装成 replicated。
- `allocateDistributedStorage` 按规范 storage 身份处理 alias；各物理副本分别重新打包、对齐和计算量化 group/channel/block 等辅助数据，再乘完整 copies。固定 bytes 分配可复制，缺少维度时拒绝隐式按比例分片。结果列出请求/规范存储 ID、设备、每份分配和全部副本 bytes，调用者仍需按规范身份去重，不能把 alias 调用结果再次累加。
- `evaluateCommunication` 验证通信前后逻辑 shape 和布局，支持 AllReduce、AllGather、ReduceScatter、AllToAll 和 send_recv 的显式声明；端点组可用不同名称复用相同物理成员。按声明发送 payload × trafficFactor 计算每发送成员的算法流量，只应用一次系数；bandwidth_latency 为发送路径时间加 startupRounds × latency。group payload 和 per-member 流量分别保留，group_total.seconds 表示集体通信跨度，不乘成员数。send_recv 仅计算两个端点，外围组闲置设备不增加 payload。
- 网络流量不被当作本地 HBM、staging buffer、归约计算或量化转换成本。未声明本地读写/HBM 的指标 unavailable，已知网络数学成本和时间仍保留。固定/自定义时间独立计算；非零流量或时间下溢不伪造为零。
- 新增严格 TensorPartition/StoragePartition/Communication 结果 Schema，生成 JSON Schema 并进行代表性 Ajv 对照。单组最多 1024 个物理设备、张量/mesh 最多 32 维；精确元素和分配超出安全整数时给出诊断。

`npm run reference:distributed` 可重跑并生成 `examples/computed/distributed-reference.json`，包含实际求值结果和明确的人工假设。C03 验证 BF16 KV 分片每卡 512 bytes、复制每卡 1024 bytes；130 元素 W4 分成两卡，每卡 65 个元素，payload 33 + scale 6 = 39 bytes，不能将全局 75 bytes 除以 2；三卡补齐后每卡 26 bytes。人工四成员 ring 验证发送 payload 1000 bytes、算法流量每成员 1500 bytes、组发送 payload 4000 bytes、整体 4.5 ms，算法系数和时间均不重复乘卡数。

验证：101 项单元/契约测试、8 项既有 Chrome 闭环、严格编译/架构检查、Schema 生成、参考命令和生产构建通过。新增用例覆盖补齐空分片、未用 mesh 轴复制、显式不均匀切片/缺口/重叠/副本冲突、手工副本、alias、局部量化、全部通信类别、范围/逻辑 shape、物理组复用、固定/公式时间及浮点下溢。

## 检查点 6：单设备串行分析与测量比较

已将结构展开接入真实计算管线与项目界面，形成一个明确受限、可复算的分析基线；P0–P6 仍未整体验收，不标记项目完成。

- 串行时间线只生成耗时已知的前缀，不虚构缺项之后的时刻。Roofline 以 executed work 为分子，分精度提供算力/带宽上限和理论点，明确 HBM 与逻辑流量口径；不同精度不合并峰值分母。
- 支持当前基线内明确的叶节点固定时间、效率、流量和规范存储 bytes 覆盖，重复/冲突或未知目标拒绝计算。多设备/并行通信、多流、方案级量化/融合及多步 decode 明确返回未支持诊断，不静默忽略输入。
- `compareMeasurement` 校对 inputHash、方案、阶段、目标与设备范围，保留 single/mean/sum/span 和 count。按类别以 useful work/匹配峰值计算 MFU，effective 能力不作为峰值；有声明的物理 HBM bytes 才计算 measured MBU，否则明确 estimated MBU。超过 100% 不截断，非零比值下溢不伪造零；测量有独立 measurementHash。
- 项目界面支持结果卡片、叶/模块成本、显存分解、串行时间线、Roofline、来源/假设/诊断、完整结果 JSON 和仅叶节点 CSV 导出；选择模型/模块/节点录入同范围单次时间，绑定当前 inputHash 并自动保存项目。比较诊断可展开，过期/未绑定测量保持待确认。

手算校验包括 C01 的 1024 operations、448 bytes、4.48 s，录入 5 s 后 MFU 20.48% / 估算 MBU 89.6%；C04 别名状态只分配 192 bytes、独立读取 384 bytes；C05 串行 8.5 ms / 峰值 3 GiB；链式激活释放、缺项峰值序号、覆盖与容量不足，以及输入哈希和测量时间归一化。

验证：固定 Node 24.22.3 下，74 项单元/契约测试、7 项 Chrome 端到端用例、严格编译/架构检查、Schema/样例生成与生产构建通过。新增浏览器路径覆盖计算、JSON/CSV 导出、测量绑定保存、参数改变后旧结果与比较失效；分析面板截图已检查。
