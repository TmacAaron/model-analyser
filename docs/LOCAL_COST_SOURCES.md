# 逐卡局部成本来源

在模型画布选择一个算子，从分析面板打开「查看画布选择的成本来源」。也可以从模型或模块的聚合运算下钻到算子。选择设备后，点击「复核此设备的局部方程」。Decode 序列先选择实际步骤。

在[融合来源](FUSION_COST_SOURCES.md)中可沿成员或附加项打开同一逐卡视图。保留的访存沿原访问 ID 对齐声明。

在张量实参及规范存储旁可展开[布局与分配推导](LAYOUT_SOURCES.md)，追溯规则、切片、填充、量化和副本。

- 打开「查看本页算式读取的实参」，可按计算段、访问字段或自定义耗时核对每个符号。设备绑定标出当前卡、实际绑定序号和数值口径，并可直接打开同一卡的张量布局或规范存储分配。即使原绑定条目在另一页，也能从当前算式进入。
- 词法参数可追到实际调用、父域、重复索引、工作负载与生效覆盖。设备绑定优先于同名词法参数，两个值相同也按实际来源区分。融合附加成本沿其声明的作用域和布局上下文复核。
- 有效工作量和执行工作量分别显示声明公式和实际实参。张量实参可查看当前卡的逻辑形状、含填充的分配形状、切片坐标和副本数。
- 存储实参保留规范存储、布局规则、每副本字节和含副本总量。分配访问显示实际采用的设备分配和访问次数。流量覆盖按本设备原读写比例分摊，HBM 沿用生效逻辑流量乘因子或独立字节公式。
- 耗时显示本设备的固定值、自定义公式或 Roofline 运算。Roofline 保留计算段顺序、精确硬件能力匹配、效率、HBM 带宽、重叠与启动耗时。点击表中的工作量或 HBM 输入可查看同一设备、同一实际步骤的计算段或访存方程。同类或等值的计算段按原始段 ID 和序号定位。调度器的串行屏障和多流时间仍由[聚合来源](AGGREGATE_COST_SOURCES.md)解释。
- 每页显示最多 20 个绑定或运算项。不可用的原指标保留该设备或步骤的诊断。

当前导出为 `local_cost_source` 版本 3，记录 Roofline 输入对应的设备指标，并优先分页显示原始方程。每个表达式证据页最多记录 256 个实参读取，界面每次展示 20 条。证据达到预算时保留原指标并标记部分记录。使用 `npm run verify:leaf-source -- <文件>` 可离线复算三个版本，核对固定配置、资产、步骤哈希、算子、设备和整页证据。模型口径的计算分类和数学成员见[逻辑工作量来源](LOGICAL_WORK_SOURCES.md)。
