# 逐卡局部成本来源

在模型画布选择一个算子，从分析面板打开「查看画布选择的成本来源」。也可以从模型或模块的聚合运算下钻到算子。选择设备后，点击「复核此设备的局部方程」。Decode 序列先选择实际步骤。

在[融合来源](FUSION_COST_SOURCES.md)中可沿成员或附加项打开同一逐卡视图。保留的访存沿原访问 ID 对齐声明。

- 有效工作量和执行工作量分别显示声明公式和实际实参。张量实参可查看当前卡的逻辑形状、含填充的分配形状、切片坐标和副本数。
- 存储实参保留规范存储、布局规则、每副本字节和含副本总量。分配访问显示实际采用的设备分配和访问次数。流量覆盖按本设备原读写比例分摊，HBM 沿用生效逻辑流量乘因子或独立字节公式。
- 耗时显示本设备的固定值、自定义公式或 Roofline 运算。Roofline 保留计算段顺序、精确硬件能力匹配、效率、HBM 带宽、重叠与启动耗时。调度器的串行屏障和多流时间仍由[聚合来源](AGGREGATE_COST_SOURCES.md)解释。
- 每页显示最多 20 个绑定或运算项。不可用的原指标保留该设备或步骤的诊断。

使用 `npm run verify:leaf-source -- <文件>` 离线复算导出的 `local_cost_source`。复算核对原配置、资产、引擎版本、步骤哈希、算子、设备、计算段和完整统计范围，再验证整份已显示证据。当前覆盖到引擎算出的设备布局与分配。布局和量化规则内部的逐式推导、逻辑工作量汇总分别审计。
