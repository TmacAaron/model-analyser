# 量化执行观察器：基础采集

检查点72接入可选的内部执行观察器，供后续量化分配来源使用。默认计算入口、公共结果协议、来源报告schema1／schema2及引擎版本保持；这一步尚未提供量化后的完整HBM来源报告或新的前端功能。

观察器只记录选定规范存储的真实作用域赋值、规则优先级与取舍、辅助项绑定，以及量化前后的实际分配器操作。事件在复制前限制为1024项、16MiB；停止采集不停止数值计算。返回数据独立复制，修改事件不能改变输入、分配或结果。普通参数采集可补充共享存储的其他实际调用域，并在完整实例化后返回快照；量化根只加入实际指定的读取，不把同域其他参数当成读取来源。

分析中的显存字节覆盖提取为同一内部步骤，仍在量化／融合之后、按分配计算访问字节之前执行。可选事件保留实际覆盖序号和前后分配；重复覆盖的执行顺序、缺失存储与alias拒绝行为保持。

当前验证包括六种作用域／共享冲突的完整结果对照、真实14B分配、选择过滤、事件修改隔离、停止／预算、后续共享调用身份和显式零字节覆盖。全部819项单元／契约、16项HTTP通过；14份既有来源报告用当前核心重放成功，16份报告及清单文件SHA保持。画布10项及来源面板5项相关Chrome通过，部分数据流用例重复运行。

尚待接入：最终分配到实际访问passes、HBM因子及原顺序求和的完整证明；相应版本化报告、Worker、UI、离线校验与固定参考。现有来源遇到量化／显存覆盖仍保留原边界，不能用量化前公式冒充最终访问。分布式、融合及其他覆盖来源和原PRD最终证据也未因此完成。
