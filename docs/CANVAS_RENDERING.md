# 大模型画布的近景与总览

重复模块默认下钻到单个实际调用。“跨调用选择算子”在同一画布呈现完整调用和真实连线。常规近景保留节点卡片、张量标签、悬浮说明和连接端口。大图近景按视窗和 64 像素边缘缓冲挂载卡片与连线。绕行的残差连线按自身路径范围判断可见，即使两端节点都在视窗外，经过视窗的路径仍会显示。

当缩放太小或视窗内的元素很密，画布在同一坐标系内绘制轻量总览。适配全图依据完整场景的节点范围，并为浮动工具栏留出空间。框选和连线命中使用场景坐标。可在工具栏打开“查找节点”，按名称或 ID 搜索当前范围，选择后定位到实际算子并聚焦。拖动过程中只重算选中坐标与相连路径，松开后将这些坐标写回工作区。

## 9,999 算子浏览器观测

使用同一个有连线的链式项目和 Chrome 157 的隔离工作区，分别记录改动前后的专项运行。从导入计时，到开启跨调用视图并确认下钻可交互。全流程还有适配、平移、拖动和分析，改动后额外检查了节点搜索与框选。这些数值包含应用、浏览器和测试调度。

| 观测项 | 改动前 | 改动后 |
| --- | ---: | ---: |
| 导入至跨调用视图就绪 | 5.21 秒 | 3.12 秒 |
| 初始近景挂载的 SVG 节点 / 连线 | 10,001 / 10,000 | 8 / 7 |
| 全流程最长动画帧间隔 | 1.80 秒 | 0.85 秒 |

适配后浏览器确认近景卡片和连线元素已卸载。总览绘制 10,001 个节点和 10,000 条连线，首尾实际像素均在适配区内。测试可定位到第 9,999 个算子，验证临近的实际连线，再跳回第一个算子、框选两项、拖动并导出。分析保留 9,999 条算子记录、0.009999 秒、159,984 B 及原固定输入哈希。

对 Qwen、DeepSeek、GLM、MoE 和三个合成边界输入比较了共 160 组范围及跨调用开关，改动前后的完整投影 JSON 相同。

`npm run test:e2e -- tests/e2e/runtime-canvas.spec.ts` 复现当前浏览器流程。场景首次投影、布局、密集总览绘制以及其他解析和序列化路径仍需分别测量。
