# 逐卡布局与分配推导

从画布的算子成本来源进入一张卡的局部方程，在张量实参旁点击「复核此卡的张量布局」，或在规范存储和分配访问旁点击「复核此卡的分配推导」。也可在成本来源范围列表中选择规范存储和设备，直接查看分配。Decode 序列选择实际步骤后使用该步配置。

- 布局证据记录原对象和轴映射、命中的规则、同级等价项和被覆盖项。每张卡可查看设备组坐标、均匀或填充分片、显式切片覆盖、手工尺寸、有效和分配元素。可捕获的原对象维度一起显示作者公式及实际实参。
- 规范存储说明其显式布局或推导它的张量分布。存在显式底层分配时，显示引擎核对的本卡需求和底层容量。
- 每副本按填充后的局部形状计算。量化记录生效规则、元素打包、字节向上取整、对齐、辅助项和物理副本乘法。辅助公式能展开实际作用域中的实参。固定字节数覆盖和融合取消物化分别标明生效阶段；已取消物化的分配为零。

每页最多 20 项。将 `layout_source` 导出后运行 `npm run verify:leaf-source -- <文件>`，验证固定输入、实际步骤、节点、对象和设备，并复算整页证据。派生对象的原声明如果没有直接捕获，则从展开图的生效维度开始；公式和量化事件达到记录预算时会标明。显示的是该步物理分配，生命周期峰值及 Decode 跨步预留在各自来源中查看。
