# 单设备叶节点的成本覆盖来源

在画布运行分析，打开成本来源，选择实际叶节点或 Decode 步骤，再复核对应指标。侧栏显示生效规则的序号、原值、覆盖值及计算过程。导出的第 4 版报告包含实际步骤和固定配置，可用 `npm run verify:leaf-source -- <文件>` 离线复算。

- **逻辑流量。** 先应用量化与显式存储分配覆盖，再用覆盖前读写访问的逻辑字节形成分母。每项按 `原访问 ÷ 原合计 × 覆盖值` 分摊。查看逻辑读取时，写入仍计入分母。逻辑写入同理。
- **HBM 流量。** 声明因子的访问将分摊后的逻辑字节乘以因子。独立声明的 HBM 字节表达式保留自身数值。报告分别列出分母求和与当前指标求和。
- **耗时。** 固定耗时直接采用显式秒值，包括零。计算或带宽效率进入设备 Roofline 运算，报告显示旧值、生效值及所用工作量、硬件能力和重叠策略。

访问每页最多 20 项。跨页仍校验原指标和全体访问的原顺序求和。报告复算核对来源字段、规则顺序、参数和实际指标，历史的第 1 至 3 版报告继续使用各自的复算协议。

适用范围为单设备串行叶节点及符合该范围的实际 Decode 步骤。分布式、融合、通信覆盖及模型或模块聚合的精确依赖仍待推进。
