# 逻辑工作量来源

点模型概览的「模型一次有效工作量」或「整个序列有效工作量」，再点「复核此逻辑工作量」。在当前结果的范围列表也可选模块、融合组和算子的逻辑工作。配置对比中的工作量差值可以分别打开基准和当前配置的来源。

| 范围 | 可复核的计算 |
| --- | --- |
| 模型和模块 | 按展开后的原始数学叶顺序累加，并计入完全属于该范围的融合附加工作 |
| 融合组 | 按数学成员顺序累加，最后加一次组内声明的额外工作 |
| 算子和融合附加项 | 按完整计算分类读取原计算段，展开公式、单位和实际实参。算子同时显示有界的实际参数绑定链 |
| Decode 序列 | 累加每个实际步骤同一范围和分类的值，保留该步固定输入哈希与求值上下文。固定上下文近似沿用该配置的求值上下文 |

分布式结果的「逻辑工作」记录数学方程声明的有效与执行工作量。物理设备工作量在模型物理汇总和逐卡来源中查看。列表每页 20 项，保留不可用诊断与原始单位。导出 `logical_work_source` 后运行 `npm run verify:leaf-source -- <文件>`，复算固定配置、资产、步骤、完整范围和显示证据。
