# 仓库目录与版本管理

Git保留可构建、可测试、可离线复算的项目文件：

| 路径 | 用途 |
| --- | --- |
| `apps/`、`packages/` | 前端、本机服务、计算核心和共享契约 |
| `assets/builtin/` | 模型、模块、算子、公式、硬件、量化等固定预设 |
| `scripts/`、`tests/` | 构建、参考生成、校验与回归测试 |
| `examples/`、`references/`、`schemas/` | 可导入的固定输入、必要的回归基线、来源样本和共享 JSON Schema |
| `docs/` | 产品与技术文档、使用和验收说明 |
| 根目录配置与锁文件 | 固定Node版本、依赖、TypeScript、Vite／测试入口 |

普通 Git 克隆即可取得测试输入。测试复用可导入的固定项目，并在需要时计算结果。少数历史结果用作冻结基线，用于发现数值、字段或协议意外变化。Ascend 完整描述文件和 Kineto trace 是导入测试的原始输入，以普通 Git 保存。

大型生成结果通过对应的 `npm run reference:*` 命令写回 `examples/`，`.gitignore` 中列出这些输出。仓库首次发布前移出了 80 个大型派生文件，体积约 1.16 GiB，原内容和 SHA256 清单保存在本机 `_local/generated-before-first-push/`。GQA 时间份额与 Qwen 融合回归改为从已保存的项目复算，并核对原有断言。

历史检查点、临时脚本、日志、探测记录、历史截图和遗留测试目录统一放在 `_local/history/`，由Git忽略。迁移清单 `relocation-manifest.json`记录原路径、归档路径、大小和SHA256，文件内容不改写。旧报告内部路径保持历史原文；归档脚本仅用于回顾，不属于当前构建或验收入口。文档中的历史证据链接指向该目录；其他克隆不自动携带这些本机记录。

`node_modules/`、`.runtime/`、`data/`及构建输出是依赖、固定运行时缓存、本机用户数据和可再生成输出，按工具约定保留工作路径，均不进入Git。用户模型与配置不移动、不删除。新的临时产物应放进 `_local/`，正式回归和参考生成入口保留在 `scripts/`。

首次提交保存整理后的当前实现，包括已经存在的量化来源增量；它不代表全项目验收完成。当前实现状态与剩余项以实施记录为准。

首次整理归档了 1,810 个根目录条目和 1,899 个文件，迁移前后 SHA256 一致。构建、6 项画布和来源浏览器检查及 841 项单元测试通过，记录保存在 `_local/`。
