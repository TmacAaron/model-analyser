## 资产定义操作

在资产库新建或打开模型/模块，“结构配置 · 资产定义”与下方完整 JSON 编辑同一份内容，修改沿用 650 ms 防抖、草稿、正式修订及冲突回执。内置资产首次修改产生用户副本；项目已有快照保持不变，需要使用 P1 的显式依赖升级。

- 编辑资产名称、模型家族/变体；参数表支持整数、数值、布尔、枚举、单位、可选默认值和范围。参数键改名不隐式改写公式，待修复的引用给出诊断。
- 插入库中模块/算子的固定修订，或添加用户声明的自定义开销节点。节点具有稳定 ID，可改名、上移/下移、删除和选择 prefill/decode。顺序不是依赖的替代品，必须用数据或控制边声明真实先后。
- 修改目标参数绑定，选择固定值、父级数值参数或固定修订公式；数值公式保留输入绑定和单位。循环索引可用作节点参数，重复次数不能引用尚未建立的自身索引。
- 配置 repeat 的循环轴、次数、独立/链式模式和 carry。更改模式不会偷偷删除旧 carry；不兼容内容留为草稿，修正后才发布。
- 模块/算子端口映射到父图张量，共享状态映射到父图状态；子定义摘要可查看内部节点，并可打开固定引用继续编辑。打开子定义不会自动修改父引用，重新选择父定义或显式升级后再使用。
- 控制/同步依赖可新增、切换类型和删除；数据连接选择来源端口、目标端口和图内张量。修改连接可删除旧边再添加新边，节点 ID 不变。
- 删除节点前展示关联边数量；确认后只清理该节点的边、状态读写和通信 placement 依赖。共享张量、存储和状态对象不被级联删除。状态创建者被删除时保留未解析引用和诊断，不虚构初始化来源。

自定义节点的简洁表单当前编辑固定秒数。完整成本（FLOPs、流量、公式、输出接口、localCost 等）、张量/存储/状态对象使用高级字段编辑器或完整 JSON；不宣称所有契约字段都已有专用表单。高级小编辑器需点击“应用”后进入自动保存链；完整资产 JSON 直接防抖保存。自定义节点初始 1 秒是界面明确展示的用户声明占位值，需要按自己的口径修改，不是系统推测的性能。

空名称仍可继续编辑并自动保存草稿。非法环、错误单位、不兼容参数绑定、缺失端口和状态引用不得发布为有效定义。表单编辑缓冲仅放宽名称/参数键等字符串的临时空值，不放宽正式 Zod 契约；其他无法解析的高级 JSON 可在完整编辑器中修复并从恢复文件保留。

## 查看包含关系与执行依赖

项目中展开模型结构，再打开“模块容器与有效叶节点”。包含树按已展开的稳定路径构建，模块和 repeat 容器逐层展开；直属叶节点每次增加 30 个。选择叶节点显示端口、shape、精度、成本及参数来源。包含树不增加父级成本；实际汇总仍只计执行叶节点/融合执行组。

依赖图实线为数据边，虚线为控制/同步边；状态创建/读取/更新在状态列表中独立展示。层级包含不能冒充数据流，跨步递归更新不能画成单步数据环。

## 可复算证据

运行 `npm run reference:editing` 生成 `examples/editing` 的模块、模型、人工硬件、完整项目、结果和独立摘要。导入 `project.json` 后直接计算：重复 3 次、每次 2 秒，再执行 3 秒 tail，共 9 秒、4 个叶节点。若要用表单编辑其库定义，按 hardware/module/model 顺序导入独立资产文件；项目仍需显式更新固定引用。

`tests/graph-editing.test.ts` 使用真实 contracts/core 核对重复绑定数值、稳定 ID、包含层级、删除共享对象策略、非法参数/端口和循环。`tests/e2e/graph-editor.spec.ts` 验证从零表单创建模块/模型、项目计算和重开、非法草稿修复、数据连接、内置副本、公式单位/绑定及延迟读取时的新编辑保留。更完整的端口/绑定/状态引用校验位于 contracts，文件层与 core 共用；没有第二份保存格式或执行图。
